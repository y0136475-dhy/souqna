# سوقنا — منصة الإعلانات والخدمات الجزائرية

هذه نسخة أولية قابلة للتشغيل من مشروع سوقنا باستخدام Next.js App Router وTypeScript وTailwind CSS وSupabase.

## ما تم تجهيزه
- واجهة عربية RTL متجاوبة.
- الصفحة الرئيسية وأقسام المنتجات والمطاعم والتوصيل والخدمات والعقارات والسيارات والوظائف والإعلانات والعروض.
- صفحة بحث مع تصفية بالقسم والولاية والسعر.
- تسجيل حساب بالبريد الإلكتروني وتسجيل الدخول عبر Supabase Auth.
- نموذج إضافة إعلان مع التحقق من المدخلات، وحفظ الإعلان بحالة `pending` لمراجعته قبل النشر.
- لوحة مستخدم تعرض إعلاناته وحالاتها، وتسجيل الخروج.
- صفحة تفاصيل الإعلان وصفحتا شروط الاستخدام والخصوصية (نصوص تأسيسية تحتاج مراجعة قانونية).
- مخطط قاعدة بيانات، بيانات تأسيسية للولايات الـ58، وسياسات RLS إضافية.
- ملف `.env.example` بلا مفاتيح سرية.

## المتطلبات
- Node.js 20 أو أحدث.
- حساب Supabase.
- npm.

## إعداد Supabase
1. أنشئ مشروعًا من https://supabase.com/
2. افتح SQL Editor وشغّل بالترتيب:
   - `supabase/migrations/001_init.sql`
   - `supabase/migrations/002_security_hardening.sql`
   - `supabase/seed.sql`
3. من إعدادات المشروع انسخ Project URL و publishable/anon key.
4. انسخ `.env.example` إلى `.env.local` وأدخل القيم:
   ```env
   NEXT_PUBLIC_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=YOUR_PUBLIC_ANON_KEY
   ```
   لا تضع `service_role` أو أي مفتاح سري في متغير يبدأ بـ `NEXT_PUBLIC_` أو في مستودع GitHub.
5. من إعدادات Authentication، اضبط عنوان الموقع وروابط إعادة التوجيه المناسبة، وقرر ما إذا كنت تريد تأكيد البريد الإلكتروني.
6. نفّذ:
   ```bash
   npm install
   npm run typecheck
   npm run build
   npm run dev
   ```
7. افتح `http://localhost:3000`.

## حساب المدير
لا يمكن إنشاء مدير عبر نموذج التسجيل. بعد إنشاء حسابك وتأكيده، استخرج معرّف المستخدم من Authentication > Users، ثم نفّذ في SQL Editor:
```sql
update public.profiles
set role = 'admin'
where id = 'ضع-معرف-المستخدم-هنا';
```
نفّذ ذلك فقط لحساب تملكه وتتحقق من هويته، ولا تمنح دور المدير لأي مستخدم غير موثوق.

## النشر
- يمكن نشر تطبيق Next.js على https://vercel.com/ أو استضافة تدعم Next.js.
- اربط مستودع GitHub، وأضف متغيرات البيئة في إعدادات الاستضافة، ثم انشر.
- تحقّق من شروط الخطط المجانية والتجارية وحدود الاستخدام والأسعار قبل الإطلاق.

## حدود النسخة الحالية — لا تعتبرها منصة تجارية مكتملة
- الصور ورفع الملفات غير منفذة بعد.
- لا توجد حتى الآن واجهة إدارية لمراجعة الإعلانات؛ يجب مراجعة `pending` وتفعيل الإعلانات من لوحة موثوقة.
- لا يوجد نظام طلبات مكتمل، ولا تتبع حي للتوصيل، ولا دفع إلكتروني، ولا نظام عمولات.
- الرسائل والمراجعات موجودة في مخطط قاعدة البيانات لكن واجهاتها لم تُنفّذ.
- لا توجد حتى الآن اختبارات شاملة أو مراجعة أمنية مستقلة.
- بيانات الإعلانات لن تظهر ما لم تُضف إلى قاعدة البيانات بحالة `active`.
- يجب مراجعة سياسات RLS وإعدادات المصادقة وقيود التخزين وإجراءات الشكاوى قبل نشر بيانات حقيقية.
- راجع شروط الاستخدام والخصوصية مع مختص قانوني في الجزائر قبل الإطلاق التجاري.

## أوامر
- `npm run dev` تشغيل التطوير.
- `npm run typecheck` فحص TypeScript.
- `npm run build` بناء نسخة الإنتاج.
- `npm start` تشغيل نسخة الإنتاج بعد البناء.
